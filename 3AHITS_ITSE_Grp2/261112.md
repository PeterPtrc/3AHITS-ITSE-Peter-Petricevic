## Übung 2.1 (Netzwerk NAT/Bridged)

### Stelle beide VMs auf Bridged Mode

- Beide VMs schließen
- Vmware öffnen
- Auf Kali-Linux gehen
- VM bearbeiten
- Auf den Tab Netzwerk klicken
- Auf "bridged" ändern

### Prüfe die ip-adressen und den gateway auf beide VMs

- Eingabe:
```sh
- ifconfig eth0
- route -n
```

- Ausgabe Kali:
Ip-Adresse (Bridged): 192.168.7.52

- Ausgabe meta:
Ip-Adresse (Bridged): 192.168.7.51

### Führe Pings aus

- Kali auf meta

- Im Kali Terminal:

- Eingabe:

```sh
ping 192.168.7.51
```

- Meta auf Kali

- Im Meta Terminal:

- Eingabe:

```sh
ping 192.168.7.52
```

### Drücken Sie die Taste Win + R und geben Sie in diesem Fenster "cmd" ein und öffnen Sie es dann

- Ping auf Kali:

- Eingabe:
```sh
ping 192.168.7.52
```

- Ping auf Meta:

- Eingabe:

```sh
ping 192.168.7.51
```

- Ping Kali an Hostsystem

- Eingabe:

```sh
ping 192.168.7.50
```

- Ping Kali auf ein anderes Kali

- Eingabe:
```sh
ping 192.168.8.52
```

Auf dem Modus "Bridged" konnte man alles pingen.

### Stelle beide VMs auf "NAT" und versuche wieder alles

- Kali IP-Address (NAT): 192.168.226.146
- Meta IP-Address (NAT): 192.168.226.143

### Führe alle Pings von vorhin aus

Auf dem Modus "NAT" konnte man alles pingen außer:
- Hostsystem auf beide VMs
- Kali auf Hostsystem
- Kali auf ein anderes Kali

## Übung 2.2 (Dateitransfer per Webserver Metasploitable → Kali)

- In Meta mithilfe von echo eine Datei mit Inhalt erstellen

- Eingabe:
```sh
echo "Hallo, Kali bitte melden. Over." > test.txt
```

- Herausfinden welcher Webserver auf Meta läuft

- Eingabe:
```sh
ps ax | sudo netstat -tlpn | grep 80
```

- Ausgabe:

Webserver: apache2

- Wo legt apache2 seine Files ab?

Ausgabe:
```sh
/var/www/
```

- Unser Verzeichnis verschieben

Eingabe:
```sh
sudo mv test.txt /var/www/test.txt
``` 

- In Kali

Eingabe:
```sh
curl http://192.168.226.143/test.txt -o test.txt
```

- Überprüfen

Eingabe:
```sh
cat test.txt
```
