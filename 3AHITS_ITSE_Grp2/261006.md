# Installation

```shell
Zuerst lade dir die 2 Zip dateien von dem USB-Stick vom Herrn Matejka auf deinen Schul-Pc runter
- kali-Linux
- metasploitable-Linux

Danach erstellen Sie ein Verzeichnis in "Dokumente" und nennen Sie es nach ihrer Wahl.
Verschieben Sie die 2 Zip-Dateien in diesen Ordner und extrahiere beide. Öffnen Sie nun VMware und starten sie die kali-Linux-Datei. 
```
# Kali-Linux

```shell
In Kali-Linux drinnen öffnen sie den Terminal. 
Keyboard auf Deutsch umstellen:
- setxkbmap de
Herunterfahren von VMware:
- shutdown -h now
```
# VScode

```shell
Im Terminal wieder (einmalig):
- wget -O vscode.deb "https://code.visualstudio.com/sha/download?build=stable&os=linux-deb-x64" 

- sudo apt install ./vscode.deb

- code .
```
