## Installieren des 2. Windows clients

- Im Lokalen Speicher (C:) liegt unser Ordner. In diesem Ordner erstellen Sie einen weiteren Ordner namens W10-2.

## VMware

### Öffnen Sie VMware und drücken sie auf "neues Projekt".
- Hostname: W10-2
- Ablageort: C:/SYTB-Name-Labor/W10-2

### Ändern Sie zusätzlich folgende Sachen:
- Prozessoren: 2
- RAM: 4GB (4096)
- Speicher: 40GB
- Netzwerk: Custom -- Vmnet0

### Im System drinnen

- ### Username & Passwort
- User: sysadmin
- passwort: Win#Sys#admin10

### !! Bitte achten Sie darauf, genau diese Login-Daten zu verwenden !!

- ### Displayauflösung

- Stellen Sie Ihre Auflösung so ein, wie es Ihnen passt.

- ### Netzwerkkonfiguration

  - Hostname: W10-2
  - IP-Adresse: 192.168.7.12 (7 wegen meinem Arbeitsplatz)
  - Gateway: 192.168.7.254  (7 wegen meinem Arbeitsplatz)
  - DNS: 1.1.1.1

- ### Aktualisieren sie das System auf den neusten Stand.

- ### Installieren Sie zusätzlichen folgende Programme:
  - Google Chrome
  - Java Runtime
  - Putty
  - Adobe Acrobat Reader
